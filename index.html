Cryptographic Architecture

🛡️

AES-256-GCM AEAD

NIST SP 800-38D authenticated encryption. Every ciphertext block is linked with a 128-bit MAC tag to instantly detect any file tampering or bit-flipping.

⏳

600,000 PBKDF2 Rounds

Key derivation with HMAC-SHA256 and a cryptographically secure 32-byte per-file salt, nullifying rainbow tables and ASIC/GPU brute-force attacks.

📦

.kromium Container v1

Open standard binary container format with magic bytes KROMIUM\0, original filename preservation, and authenticated header AAD.

⚡

Zero-Knowledge Offline

All cryptographic operations run locally on the client machine. Zero server telemetry, zero external APIs, zero third-party dependencies.
